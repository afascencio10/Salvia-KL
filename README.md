## Desarrollo en una sesión cloud de Claude Code
Para correr la plataforma, entrar con Playwright y probar un requerimiento en el sandbox cloud: ver `cloudDevelopment/README.md` (inicio rápido: `./run_dev.sh`; 19 usuarios de prueba, uno por rol).

`cloudDevelopment/` es **solo** el setup y los datos para correr la app en ese sandbox: no lleva scripts de QA ni nada que no sea preparar el entorno o sus datos (ver «Alcance de esta carpeta» en su README).
